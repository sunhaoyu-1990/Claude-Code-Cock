# Frontend 示例项目

这是一个展示如何使用 Claude Code 驾驶舱框架的 React + TypeScript 前端示例项目。

## 项目特点

- ✅ 配置了完整的 Claude Code 规范
- ✅ 使用 React 18 + TypeScript
- ✅ 使用 Vite 构建工具
- ✅ 包含组件测试
- ✅ ESLint + Prettier

## 快速开始

```bash
# 安装依赖
npm install

# 开发服务器
npm run dev

# 构建
npm run build

# 运行测试
npm run test
```

## Claude Code 使用

本项目的 Claude Code 配置位于 `CLAUDE.md`，包含：

- React + TypeScript 最佳实践
- 组件开发规范
- 状态管理指南
- 测试策略

## 项目结构

```
frontend-example/
├── src/               # 源代码
│   ├── components/    # React 组件
│   ├── hooks/         # 自定义 Hooks
│   ├── types/         # TypeScript 类型
│   └── utils/         # 工具函数
├── tests/             # 测试文件
├── CLAUDE.md          # Claude Code 配置
├── package.json       # 项目配置
└── README.md          # 本文件
```
