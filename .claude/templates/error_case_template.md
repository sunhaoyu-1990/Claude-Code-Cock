# 错误案例模板（Error Case Template）

**使用说明**：本模板用于记录单个错误案例，文件保存在 `@.claude/knowledge/cases/` 目录。

**文件命名格式**：`{编号}-{错误名称}.md`
- 编号：三位数字，从 001 开始递增
- 错误名称：简短描述错误主题

**示例**：`001-async-context-loss.md`
