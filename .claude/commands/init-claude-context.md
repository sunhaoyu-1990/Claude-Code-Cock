你现在是一个项目初始化专家，你的任务是：

> **为新项目初始化 Claude Code 配置并生成 CLAUDE.md 文件**

本命令支持两种模式：
- **自动模式（--auto）**：基于需求文件自动生成，不与用户交互
- **互动模式（--interactive）**：引导用户提供信息逐步生成

请严格按照下面步骤执行。

---

## 执行流程概览

```
开始
  ↓
检测需求文件
  ↓
  ├─ 找到需求文件 → 读取需求文件内容
  └─ 未找到 → 提示用户选择：提供需求文件 / 直接互动
      ↓
  询问用户选择模式
      ↓
    ┌───┴───┐
    ↓       ↓
自动模式  互动模式
    ↓       ↓
基于需求   逐步引导
生成配置  用户填写
    ↓       ↓
    └───┬───┘
        ↓
    生成 CLAUDE.md
        ↓
    验证配置
        ↓
    完成
```

## 步骤 1：检测需求文件

### 1.1 查找常见需求文件

检测以下文件是否存在（按优先级）：

```bash
# 常见需求文件
ls README.md 2>/dev/null
ls SPEC.md 2>/dev/null
ls spec.md 2>/dev/null
ls docs/SPEC.md 2>/dev/null
ls docs/requirements.md 2>/dev/null
ls PRD.md 2>/dev/null
ls docs/PRD.md 2>/dev/null
ls REQUIREMENTS.md 2>/dev/null
ls .claude/SPECS/*/spec.md 2>/dev/null
```

### 1.2 判断结果

**情况 A：找到需求文件**
- 记录找到的文件路径
- 进入步骤 2：读取需求文件

**情况 B：未找到需求文件**
- 提示用户：
  ```markdown
  ## 未找到需求文件

  未检测到项目中的需求文档（README.md、SPEC.md 等）。

  请选择：
  - **A**：提供需求文件路径（我可以读取）
  - **B**：直接进入互动模式，由您提供项目信息
  - **C**：取消操作
  ```
- 等待用户选择

## 错误处理

### 错误 1：模板文件不存在

**原因**：`.claude/templates/CLAUDE-tem.md` 不存在

**处理**：
```bash
# 检查框架是否正确安装
ls .claude/templates/CLAUDE-tem.md

# 如果不存在，提示用户先安装框架
echo "请先安装 Claude Code 框架"
```

### 错误 2：无法写入 CLAUDE.md

**原因**：文件已存在或权限不足

**处理**：
```bash
# 检查文件是否存在
ls CLAUDE.md

# 如果存在，询问用户
echo "CLAUDE.md 已存在，是否覆盖？(y/n)"
```

### 错误 3：用户取消操作

**原因**：用户在任何步骤选择取消

**处理**：
- 保存已收集的信息（如果有）
- 提供下次继续的选项
- 清理临时文件

## 命令参数

### --auto（自动模式）

快速启动，基于需求文件自动生成：

```bash

/init-claude-context --auto
```

逐步引导生成：

```bash
# 在 Claude Code 中调用
/init-claude-context --interactive
```

### 无参数

默认行为：
1. 检测需求文件
2. 如果找到，显示模式选择
3. 如果未找到，直接进入互动模式
