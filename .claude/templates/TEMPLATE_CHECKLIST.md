# 模板检查清单（Template Checklist）

**版本**：v1.0
**适用对象**：Claude Code 和项目维护者
**目的**：确保项目模板文件的完整性和正确性

---

## 概述

本检查清单用于验证 Claude Code 驾驶舱框架的所有模板文件是否符合规范要求。

**检查范围**：
- 项目级配置模板（CLAUDE.md、PROJECT_CONTEXT.md）
- 规格说明模板（spec.md）
- 计划模板（plan.md）
- 检查清单模板（checklist.md）
- 任务模板（tasks.md）
- 错误处理模板（error_case、error_pattern）

---

## 1. 项目级配置模板

### 1.1 CLAUDE.md 检查清单

#### 文件存在性

- [ ] 文件存在于项目根目录
- [ ] 文件名为 `CLAUDE.md`（全大写）

#### 必填占位符

- [ ] `{项目名称}` 已填写
- [ ] `{主要语言}` 已填写
- [ ] `{语言版本}` 已填写
- [ ] `{主要框架}` 已填写
- [ ] `{测试框架}` 已填写

#### Profile 引用

- [ ] 引用了至少一个 Language Profile
- [ ] 引用路径格式正确：`@.claude/PROFILES/{language}.md`
- [ ] 使用的 Profile 与项目语言匹配

#### 规范引用

- [ ] 引用了 `@.claude/BASE_CLAUDE.md`
- [ ] 引用了 `@.claude/constitution.md`
- [ ] 引用了 `@.claude/knowledge/patterns/`（错误模式）

#### 内容完整性

- [ ] 项目描述清晰
- [ ] 技术栈明确
- [ ] 开发规范已声明

**验证命令**：
```bash
python .claude/scripts/validate_template.py
```

## 7. 全局检查项

### 7.1 路径引用规范

- [ ] 所有路径使用 `/` 而非 `\`（跨平台兼容）
- [ ] Constitution 引用：`@.claude/constitution.md`
- [ ] BASE 引用：`@.claude/BASE_CLAUDE.md`
- [ ] Profile 引用：`@.claude/PROFILES/{language}.md`
- [ ] 模板引用：`specs/templates/{template}.md`
- [ ] 错误知识引用：`@.claude/knowledge/`

**验证命令**：
```bash
python .claude/scripts/check_templates.py
```

### 7.2 编码规范

- [ ] 文件编码为 UTF-8
- [ ] 换行符与项目一致（LF / CRLF）
- [ ] 无 BOM 头

### 7.3 版本控制

- [ ] 模板文件已提交到版本控制
- [ ] `.gitignore` 不排除模板文件

## 8. 自动化验证脚本

### 8.1 运行所有检查

```bash
# 验证模板占位符
python .claude/scripts/validate_template.py

# 检查模板文件和引用
python .claude/scripts/check_templates.py

# 检查规范合规性
python .claude/scripts/check_compliance.py

# 检查工作流状态
python .claude/scripts/check_workflow.py
```

### 8.2 预期结果

所有脚本应返回 `0` 退出码，无错误信息。

## 9. 问题处理流程

### 9.1 发现问题时

1. **记录问题**：在 todo list 中标记
2. **分析根因**：确定问题来源
3. **修复问题**：更新模板或配置
4. **重新验证**：运行检查脚本确认

### 9.2 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 占位符未填写 | 模板复制后未修改 | 填写必填项 |
| 路径引用错误 | Windows 路径风格 | 替换 `/` 为 `\` |
| Profile 缺失 | 引用了不存在的 Profile | 创建或更换 Profile |
| 规范冲突 | 多个规范不一致 | 按优先级裁决 |

## 10. 持续改进

### 10.1 模板更新流程

1. 在 `.claude/` 项目中更新模板
2. 同步到各项目
3. 更新检查清单
4. 通知团队成员

### 10.2 检查清单维护

- 定期审查检查项的有效性
- 根据实际情况调整检查项
- 记录检查清单的版本历史
